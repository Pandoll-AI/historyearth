# 결정 기록 (historyearth)

| 번호 | 결정 | 이유 |
|---|---|---|
| D-001 | 지도 엔진은 CesiumJS 대신 **MapLibre GL JS v5**(globe 투영 + raster-dem 지형)로 한다 | Cesium World Terrain·기본 영상은 ion 토큰이 필요하다. MapLibre는 토큰 없이 지구본·대기·3D 지형을 다 하고 묶음 크기가 더 작다(gzip 약 270KB). |
| D-002 | 위성 영상은 EOX Sentinel-2 cloudless **2016판(CC BY 4.0)** 을 쓴다 | 2018년 이후판은 CC BY-NC-SA라 수업 외 공개 배포에 제약이 있다. 키 없이 쓰고 CORS가 열려 있다. |
| D-003 | 지형은 AWS Terrain Tiles(Terrarium)를 쓴다 | 무료·무키·CORS 허용, MapLibre가 terrarium 인코딩을 직접 지원한다. |
| D-004 | 세계 국경은 historical-basemaps 46개 시점을 5%로 단순화해 시점별 파일로 나눠 필요할 때만 불러온다 | 원본 61MB → 전체 9.4MB, 한 시점 gzip 10~200KB. GPL-3.0이라 README에 명시한다. |
| D-005 | 한반도는 자체 다각형(55개 구간)을 따로 그리고, 그 해에 자체 영역이 있으면 basemap의 한반도 쪽 나라는 숨긴다 | 명세가 한국사 영토를 직접 만들라고 했고, basemap과 겹치면 색이 뒤섞인다. 동시대 나라끼리는 우선순위로 빼기(difference)를 해서 겹치지 않게 했다. |
| D-006 | 라벨은 지도 글꼴 서버 대신 DOM(외곽선 글자+점+리더선)으로 그리고 지구 뒷면은 역투영 검사로 숨긴다 | 한글 글리프 서버가 필요 없고, 명세의 "외곽선+점+리더선" 모양을 그대로 낼 수 있다. |
| D-007 | 기온은 Open-Meteo(ERA5) 2024년 1월·7월 월평균을 6° 격자로 받아 앱에 넣는다(17KB) | 무키 공개 자료 중 가장 가볍게 실제 값을 쓸 수 있다. 하루 요청 한도 안에서 받으려고 1년치·6° 간격으로 정했다. |
| D-008 | 바람·먼지 흐름은 관측 자료 대신 단순화한 함수로 만들고 화면에 "설명용 그림"이라고 표시한다 | 바람장 실데이터는 크고, 수업 목적에는 큰 흐름이 더 중요하다. |
| D-009 | 전 지구 래스터(밤 그림자·기온)는 90° 조각 4장의 image source로 나눠 올린다 | 360° 한 장짜리 image source는 globe에서 그려지지 않았다(실측). |
| D-010 | 시대 버튼에 "백제 전성기 371", "신라 전성기 568", "오늘날"을 더해 16개로 했다 | 명세 목록의 "백제·고구려·신라 전성기"를 나눠 각 나라 확대를 보여 주기 위해. |
| D-011 | 휴대폰(폭 760px 이하)에서는 오른쪽 위 버튼들을 ☰ 메뉴로 접고, 지리 설명 패널은 숨긴다 | 지구본 화면을 가리지 않게. 지형 과장 막대는 메뉴 안에 둔다. |
| D-012 | 배포는 Vercel 커넥터 업로드(정적 dist), 저장소는 Pandoll-AI private | dev-preferences의 기존 절차를 따른다. |
| D-013 | Playwright 모바일 테스트는 deviceScaleFactor 1로 돌린다 | 박스에 GPU가 없어(SwiftShader) 고해상도 화면 캡처가 시간 초과됐다. 레이아웃은 같은 CSS 픽셀 크기로 확인된다. |
